Backend development: `npm run dev` (tsx watch), `npm run build` (prisma generate + tsc), `npm run seed` (seedAdmin script), `npm run prisma:studio` for DB inspection. Database migrations use `prisma db push` or `prisma migrate dev`; production start is `node dist/index.js`. Frontend development: `npm run dev` (Vite), build via `tsc -b && vite build`. Environment variables are loaded from `.env` (JWT_SECRET, DATABASE_URL, Gemini keys) with `.env.example` templates provided.
