The backend is an Express app (`backend/src/index.ts`) that mounts feature route modules under `/api/*` and applies a global error handler; the admin feature lives in `routes/admin.ts`, which is mounted at `/api/admin` and protected by a single `adminAuthMiddleware` applied at router level so every admin endpoint requires a Bearer JWT whose payload user has `isAdmin: true`. The admin route module is the central orchestration layer: it reads query params for filtering (status lists via comma-separated values, scoped views via `?user=` / `?vehicle=`), performs Prisma queries with selective `include`/`select` payloads, validates inputs inline, and delegates business side-effects to services like `payoutService.recalculatePayout` (e.g. when vehicle valuation changes). Frontend admin pages live under `frontend/src/pages/admin/` and are gated by `AdminProtectedRoute`; they call a dedicated `services/adminApi.ts` client that prefixes requests with the same `/api/admin` path. Shared layout and auth context live in `components/` and `context/AuthContext.tsx`, keeping the admin SPA separate from the regular user/garage apps while reusing the same token format.
