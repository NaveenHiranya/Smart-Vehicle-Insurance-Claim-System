The module is split across backend and frontend with a clear separation of concerns. The Express server (`backend/src/index.ts`) mounts an `/api/admin` route group that is globally protected by `adminAuthMiddleware`, which verifies a JWT and enforces `user.isAdmin`. The `routes/admin.ts` router exposes REST endpoints for stats, users, claims (list/detail/status), documents (approve/reject), garage management (approve/toggle), and per-claim admin notes — all backed by Prisma queries against the shared SQLite schema (`prisma/schema.prisma`). A one-off seed script (`scripts/seedAdmin.ts`) creates the default admin user. On the frontend, React pages under `src/pages/admin/*` are guarded by `AdminProtectedRoute`, which checks for an `adminToken` in localStorage and redirects to `/admin/login`. All admin API calls go through a dedicated `services/adminApi.ts` axios instance that injects the token and auto-redirects on 401/403 responses. Dependency direction: frontend → `/api/admin` routes → middleware → Prisma client; no cross-talk between admin and regular user routes beyond sharing the same database.
