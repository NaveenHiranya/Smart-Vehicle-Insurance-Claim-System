Single-process Express 5 application bootstrapped in `src/index.ts` that validates required env vars (`JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`), mounts CORS, JSON parsing, static `/uploads` serving, and registers nine feature routers under `/api/*`. The data layer is Prisma Client over SQLite (`prisma/schema.prisma`) with models centered on the `Vehicle` entity — each vehicle owns one optional `InsurancePolicy`, and claims are always linked to a verified vehicle's policy. Business logic is split into thin route handlers (in `src/routes/`) that delegate domain work to pure service modules in `src/services/` (damage analysis, repair estimate, document verification, fraud scoring, payout recalculation, notifications, part catalog, vehicle detection, assistant chat). Cross-cutting concerns live in `src/middleware/`: JWT bearer auth, admin-only and garage-only guards, a global error handler, and Multer-based image/document upload. External AI capabilities are abstracted behind `src/utils/gemini.ts` and `imageUtils.ts`. Seed scripts under `src/scripts/` run idempotently at startup to ensure built-in policy templates exist. Deployment targets Railway via `railway.toml` with Node 20+.
