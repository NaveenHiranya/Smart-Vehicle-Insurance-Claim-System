Single-page app bootstrapped in `main.tsx` with React Router v7 (`App.tsx`) defining three route namespaces: `/` (policyholder), `/admin/*` (admin portal), and `/garage/*` (garage portal). Each namespace is wrapped by a dedicated layout component (`Layout`, `AdminLayout`, `GarageLayout`) and guarded by role-specific route guards (`ProtectedRoute`, `AdminProtectedRoute`, `GarageProtectedRoute`). Authentication state (user, token, login/register/logout) lives in a single `AuthContext` that persists the JWT in `localStorage` and auto-refreshes the profile on mount. HTTP calls are centralized through an Axios instance in `services/api.ts` (with Bearer-token interceptor and 401 redirect), extended by domain-scoped clients `adminApi.ts` and `garageApi.ts`. All shared TypeScript models (User, Vehicle, Policy, Claim, GarageEstimate, etc.) are declared in `src/types/index.ts`, making the types the contract between pages, services, and components. Role-specific feature modules are organized as sibling directories under `pages/` (e.g. `pages/admin/`, `pages/garage/`), while reusable UI pieces live in `components/` (layouts, protected routes, brand panels, AI assistant, notification bell). Build/runtime configuration is driven by Vite (`vite.config.ts`) with Tailwind CSS via `@tailwindcss/vite`, dev proxying `/api` and `/uploads` to the backend, and environment variables resolved from `.env` / `VITE_API_URL`.
