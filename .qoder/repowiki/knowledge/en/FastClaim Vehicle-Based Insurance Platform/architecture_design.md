Two sibling Node.js applications share the workspace root as their orchestration point: `backend/` exposes an Express REST API (routes → controllers → services → Prisma schema) that persists vehicle/policy/claim data in SQLite (`prisma/dev.db`) and serves uploaded images/documents from `uploads/`; `frontend/` is a Vite+React SPA consuming that API through role-scoped service modules (`api.ts`, `adminApi.ts`, `garageApi.ts`) and rendering three portals gated by `ProtectedRoute`, `AdminProtectedRoute`, and `GarageProtectedRoute`. Cross-child communication is purely HTTP over a shared base URL configured via environment variables; there is no shared code between them. The root `package.json` scripts (`dev:backend`, `dev:frontend`, `build`, `seed`) coordinate local development, while `railway.toml` defines the production build/deploy pipeline that runs Prisma migrations before starting the backend.
