The project is split into two independent applications sharing a Prisma schema under `backend/prisma/schema.prisma`:

- **Backend (`backend/src`)**: An Express 5 server bootstrapped in `index.ts` that validates required env vars (`JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`), mounts CORS, serves static uploads from `uploads/`, and registers route groups under `/api/{auth,vehicles,policies,claims,admin,garage/auth,garage,general-chat}`. Each route group lives in its own file under `src/routes/`. Business logic is delegated to `src/services/*` (claim assistant, damage analysis, document verification, repair estimate, vehicle detection) which call Google Gemini via `utils/gemini.ts`. Authentication uses JWT (`jsonwebtoken`) stored client-side; authorization is enforced per-route-group via middleware in `src/middleware/` — `auth.ts` for regular users, `adminAuth.ts` for the admin namespace (checks `Bearer` token + `user.isAdmin` flag), `garageAuth.ts` for garage accounts, plus `errorHandler.ts` and `upload.ts` (multer).
- **Database**: SQLite via Prisma Client (`@prisma/client`). The schema defines the core domain: `User`, `Vehicle`, `PolicyTemplate`, `InsurancePolicy`, `Claim` (with `ClaimStatus` enum), `ClaimImage`, `DamageAssessment`, `RepairEstimate`, `InsurancePayout`, `Document` (with `VerificationStatus`), `ChatMessage`, `AdminNote`, `Garage`, and `GarageEstimate`, all linked with cascade or set-null relations.
- **Frontend (`frontend/src`)**: A Vite + React 19 SPA using `react-router-dom` for routing. Admin UI is isolated under `pages/admin/*` and wrapped in `components/AdminLayout.tsx` with a collapsible sidebar and `AdminProtectedRoute.tsx`. User and garage UIs live under `pages/` and their own layouts. API clients are split by role: `services/api.ts` (user), `services/adminApi.ts` (admin, auto-injects `adminToken` from `localStorage` and redirects on 401/403), and `services/garageApi.ts`. Shared types live in `frontend/src/types/index.ts`; utilities include `garageEstimate.ts` and `uploadUrl.ts`.
- **Dependency direction**: Frontend → backend REST API only; backend → Prisma Client + Google Gemini + filesystem uploads. There is no shared code between the two apps — they communicate purely over HTTP.
