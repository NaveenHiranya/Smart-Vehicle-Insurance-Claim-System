Backend requires copying `backend/.env.example` to `backend/.env` and setting `JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL` before starting — startup exits if any are missing. Development: `npm run dev` (tsx watch). Build: `npm run build` (runs `prisma generate && tsc`). Database: `npm run prisma:migrate` / `prisma:push` / `prisma:studio`. Seed initial admin account via `npm run seed` (`src/scripts/seedAdmin.ts`). Frontend: `npm run dev` (Vite), build via `tsc -b && vite build`.
