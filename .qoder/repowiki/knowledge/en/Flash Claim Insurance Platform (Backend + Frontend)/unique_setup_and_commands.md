Backend requires copying `backend/.env.example` to `backend/.env` with `JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`, and optionally `CORS_ORIGIN` and `UPLOAD_DIR`; missing vars cause startup exit. Development: `npm run dev` (tsx watch) or `npm run start:migrate` (runs `prisma db push` then starts). Seed built-in policy templates and an admin user via `npm run seed`. Frontend: `npm run dev` (Vite on port 5173 by default).
