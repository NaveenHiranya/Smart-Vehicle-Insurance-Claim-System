The repository is a monorepo with two top-level applications sharing a common domain model defined in Prisma (`backend/prisma/schema.prisma`).

Backend (`backend/src`): an Express 5 server bootstrapped in `index.ts`, which validates required env vars (`JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`), mounts CORS, serves static uploads from `UPLOAD_DIR`, and registers route groups under `/api/auth`, `/api/vehicles`, `/api/policies`, `/api/claims`, `/api/admin`, `/api/garage/*`, and `/api/general-chat`. A global `errorHandler` middleware catches all errors. Each feature area lives in its own `routes/*.ts` file; business logic is extracted into `services/` (claim assistant, damage analysis via Google Gemini, document verification, payout recalculation, repair estimates, vehicle detection, policy template seeding). Authentication is layered: `middleware/auth.ts` validates JWTs for regular users, `middleware/adminAuth.ts` additionally checks `user.isAdmin`, and `middleware/garageAuth.ts` guards garage routes. File uploads go through `multer` + `sharp` image compression into `uploads/images` and `uploads/documents`, served statically.

Frontend (`frontend/src`): a React + Vite SPA using `react-router-dom` for routing. `App.tsx` declares three role-based route trees — user (`/dashboard`, `/claims`, `/vehicles`, `/policies`), admin (`/admin/*`), and garage (`/garage/*`) — each wrapped in a role-specific protected route component (`ProtectedRoute`, `AdminProtectedRoute`, `GarageProtectedRoute`) that reads tokens from `localStorage` (`token` vs `adminToken`). Shared layouts (`Layout`, `AdminLayout`, `GarageLayout`) provide navigation chrome. API calls are centralized in `services/api.ts`, `services/adminApi.ts`, and `services/garageApi.ts`, typed against shared `types/index.ts` on both sides.

Dependency direction: Frontend → Backend REST API only; backend → Prisma client → PostgreSQL (SQLite dev DB); services depend on Prisma and external AI APIs but never on Express types. The admin dashboard is a full separate portal with its own login flow and dedicated `/api/admin` endpoints covering users, vehicles, claims, documents, garages, and policy templates.
