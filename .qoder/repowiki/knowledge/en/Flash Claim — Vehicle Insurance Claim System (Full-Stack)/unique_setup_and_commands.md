Backend requires copying `backend/.env.example` to `backend/.env` with `JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`, and optionally `CORS_ORIGIN` / `UPLOAD_DIR`; startup fails if any of the three required env vars are missing. Development uses `npm run dev` (tsx watch), build is `prisma generate && tsc`, and seed data is run via `npm run seed` (`seedAdmin.ts` + `seedPolicyTemplates.ts`). Database schema is pushed with `prisma db push` or migrated with `prisma migrate dev`.
