The application is bootstrapped in `src/index.ts`, which mounts global middleware (CORS, JSON parsing, static `/uploads` serving) and registers five route groups under `/api/{auth,vehicles,policies,claims,admin}`. Each route group delegates business logic to domain-specific services in `src/services/` (claims management, damage analysis, document verification, repair estimates, vehicle detection), while cross-cutting concerns are centralized: JWT-based auth and admin-only guards live in `src/middleware/`, the Prisma client is shared via `src/utils/prisma.ts`, and all errors funnel through a single `errorHandler`. Uploaded images/documents are persisted under `backend/uploads/` and served statically, and Google Gemini vision is invoked from services via `src/utils/gemini.ts`. The Prisma schema in `prisma/schema.prisma` defines the single source of truth for claims, vehicles, policies, users, and documents consumed by every service.
