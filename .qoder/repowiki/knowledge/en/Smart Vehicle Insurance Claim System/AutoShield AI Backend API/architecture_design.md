The entry point `src/index.ts` bootstraps an Express app, mounts CORS/JSON parsing, serves uploaded files from `./uploads`, then registers four domain route modules under `/api/{auth|vehicles|policies|claims}` before attaching a global error handler. Domain routes delegate business logic to `services/` (claim assistant, damage analysis, document verification, repair estimate), which in turn call Gemini via `utils/gemini.ts` and persist data through `utils/prisma.ts`. Cross-cutting concerns—authentication, file upload, and centralized error handling—are implemented as reusable middleware in `middleware/` and applied uniformly across all routes. Shared TypeScript types live in `types/index.ts` consumed by both routes and services.
