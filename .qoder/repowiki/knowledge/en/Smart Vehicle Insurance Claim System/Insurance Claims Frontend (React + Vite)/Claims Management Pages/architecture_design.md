Three sibling React functional components mounted under the app's routing: `ClaimsPage` lists user claims with status filtering via `GET /claims?status=...`; `NewClaimPage` implements a four-step wizard (incident info → full-vehicle photos → damage close-ups → review & submit) that POSTs `/claims`, uploads images to `/claims/{id}/images`, then submits via `/claims/{id}/submit`; `ClaimDetailPage` fetches a single claim via `GET /claims/{id}` and exposes actions for AI analysis (`POST /claims/{id}/analyze`), document upload/verification (`POST /claims/{id}/documents`, `/claims/{id}/documents/{id}/verify`), and a per-claim chat assistant (`POST /claims/{id}/chat`). All pages consume a shared `api` client from `../services/api`, share TypeScript types from `../types`, and render UI with Tailwind CSS and Lucide icons. Navigation between pages uses `react-router-dom` (`Link`, `useNavigate`, `useParams`, `useSearchParams`).
