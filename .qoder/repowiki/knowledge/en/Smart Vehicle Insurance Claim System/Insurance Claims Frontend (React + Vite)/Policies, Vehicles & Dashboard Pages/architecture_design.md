Three sibling React function components exported from `src/pages/`: `DashboardPage` aggregates a welcome header, stat cards (vehicles, active claims, total claims), quick-action links, and a recent-claims list; `PoliciesPage` provides inline add/delete for `InsurancePolicy` records via a toggleable form; `VehiclesPage` exports three components — `VehiclesPage` (list + link to create), `VehicleDetailPage` (detail view with claim history and delete), and `AddVehiclePage` (create form). All pages fetch data through a shared `../services/api` axios instance against `/policies`, `/vehicles`, and `/claims` endpoints, consume typed models from `../types`, render UI with Tailwind CSS classes, and use `lucide-react` icons. Navigation is handled by `react-router-dom` (`Link`, `useNavigate`) rather than client-side routing logic inside the pages. The dashboard additionally reads the current user from `../context/AuthContext` to personalize the greeting.
