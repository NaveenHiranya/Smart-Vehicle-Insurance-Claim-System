Two sibling services share the same domain model: the `frontend/` React SPA communicates over HTTP with the `backend/` Express API, which persists data through a shared Prisma schema. The root level only holds repository-level configuration (`.gitignore`, `.qoder/`) and delegates all runtime concerns to the two child modules; there is no cross-child orchestration code at this level beyond the implicit contract that the frontend calls the backend's REST endpoints.
