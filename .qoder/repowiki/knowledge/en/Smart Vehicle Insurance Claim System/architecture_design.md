The workspace is split into two sibling services — `backend/` (Express server with Prisma, Gemini-powered claims, and domain routes) and `frontend/` (React SPA consuming the backend via a shared API client). There is no monorepo build tool; each child runs independently, with the frontend pointing at the backend's base URL to form the full application. The only shared concern at this level is version pinning of cross-cutting dependencies (e.g., Node.js, package managers) and repository-wide ignore rules in `.gitignore`.
