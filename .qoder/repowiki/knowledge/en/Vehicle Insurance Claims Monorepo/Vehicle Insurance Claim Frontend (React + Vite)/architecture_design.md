Single-page application bootstrapped via `src/main.tsx` rendering into `#root`, with routing defined in `src/App.tsx` using `react-router-dom`. The app is split into two role-based route trees under `/` (customer) and `/admin/*` (admin), each protected by dedicated route guards (`ProtectedRoute`, `AdminProtectedRoute`) and wrapped in corresponding layouts (`Layout`, `AdminLayout`). Authentication state (user, token, loading) lives in a React Context (`src/context/AuthContext.tsx`) that persists tokens to `localStorage` and validates sessions on mount. HTTP communication is centralized in two Axios instances: `services/api.ts` (base `/api`, Bearer token from `token`, redirects on 401) and `services/adminApi.ts` (base `/api/admin`, Bearer token from `adminToken`, redirects on 401/403). Shared TypeScript domain models (`types/index.ts`) define User, Vehicle, Claim, Policy, Document, DamageAssessment, RepairEstimate, etc., consumed by both customer and admin pages. Pages are organized as feature folders under `src/pages/` (customer) and `src/pages/admin/` (admin), while reusable UI shells live in `src/components/`. Styling uses Tailwind CSS v4 via `@tailwindcss/vite` plugin; dev server proxies `/api` and `/uploads` to `http://localhost:5000`.
