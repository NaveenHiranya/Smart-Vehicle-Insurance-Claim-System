Two sibling services share the same domain model: the `frontend/` React SPA communicates over HTTP with the `backend/` Express API, which persists data through Prisma. The root level holds only repository-level configuration (`.gitignore`, `.qoder/`) and delegates all runtime concerns to the child modules; there is no cross-child orchestration code at this level beyond the implicit REST contract where the frontend calls the backend's endpoints. An admin dashboard under `/admin` in the frontend provides a separate login flow that operates on the same backend APIs to manage users, claims, documents, and status changes.
