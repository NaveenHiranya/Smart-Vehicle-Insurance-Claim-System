The project is split into two sibling applications sharing a common domain model:

- Backend (`backend/src`): Express server bootstrapped in `index.ts`, which validates required env vars (`JWT_SECRET`, `GEMINI_API_KEY`, `DATABASE_URL`), mounts CORS, serves static uploads from `UPLOAD_DIR`, and registers route groups under `/api/{auth,vehicles,policies,claims,admin,garage/auth,garage,general-chat}`. A global `errorHandler` middleware catches errors. Routes delegate to controllers (not shown) and then to domain services in `services/` (claim assistant, damage analysis, document verification, payout, repair estimate, vehicle detection). Prisma client (`utils/prisma.ts`) targets an SQLite database defined in `prisma/schema.prisma`, which models the core entities: `User`, `Vehicle` (with `verificationStatus: PENDING|VERIFIED|REJECTED`), `PolicyTemplate`, `InsurancePolicy` (one per vehicle via unique `vehicleId`), `Claim` (tied to `vehicleId` + optional `policyId`), plus supporting tables for images, damage assessments, repair estimates, garage estimates, documents, chat messages, admin notes, and `Garage`. Startup seeds built-in policy templates idempotently via `seedPolicyTemplates()`.
- Middleware layer (`middleware/`): role-scoped auth guards (`auth.ts`, `adminAuth.ts`, `garageAuth.ts`) plus file upload handling (`upload.ts`).
- Frontend (`frontend/src`): React/Vite app with `BrowserRouter` routing in `App.tsx`, three role-based layouts (`Layout`, `AdminLayout`, `GarageLayout`) and corresponding protected-route wrappers (`ProtectedRoute`, `AdminProtectedRoute`, `GarageProtectedRoute`). Pages are grouped by role under `pages/`, `pages/admin/`, `pages/garage/`. Auth state lives in `context/AuthContext.tsx`. API calls go through typed clients in `services/api.ts`, `services/adminApi.ts`, `services/garageApi.ts`. Shared types live in `types/index.ts` on both sides.

Dependency direction: frontend → backend REST APIs; backend routes → services → Prisma client → SQLite. The vehicle-centric schema enforces that claims can only be created for verified vehicles and that payouts derive from the vehicle's attached policy.
